# Описание выполнения Домашнего задания 1
## Задание 1: Верстка страниц на Bootstrap
Созданы 4 HTML страницы:
1. `index.html` - Главная страница
2. `catalog.html` - Каталог товаров
3. `category.html` - Страница категории
4. `contacts.html` - Контакты
## Задание 2: Простой HTTP сервер
Файл `server.py` содержит:
- Обработчик GET запросов (возвращает contacts.html)
- Обработчик POST запросов (выводит данные в консоль)
- Поддержка UTF-8 кодировки
- Возможность смены порта через аргументы

## Структура проекта:
- `/templates/` - HTML шаблоны
- `/screenshots/` - Папка для скриншотов
- `server.py` - HTTP сервер
- `README.md` - Документация
- `.gitignore` - Исключения Git
