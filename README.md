# Интернет-магазин - Учебный проект

Проект создается в рамках обучения веб-разработке на Django.

## Структура проекта

online-store/

│ ├── index.html # Главная страница
│ ├── catalog.html # Каталог товаров
│ ├── category.html # Страница категории
│ └── contacts.html # Контакты
├── screenshots/ # Скриншоты (для ДЗ 3)

## Домашнее задание 1

### Задание 1: Верстка страниц
Созданы 4 HTML страницы с использованием Bootstrap 5:
1. **Главная страница** (`index.html`) - содержит герой-секцию, популярные товары и преимущества магазина
2. **Каталог товаров** (`catalog.html`) - страница с фильтрами и списком товаров
3. **Страница категории** (`category.html`) - детальная страница категории с подкатегориями
4. **Контакты** (`contacts.html`) - контактная информация и форма обратной связи

### Задание 2: Простой веб-сервер
Создан простой HTTP сервер на Python (`server.py`), который:
- На любой GET запрос возвращает страницу контактов (`contacts.html`)
- Читает HTML файл через `open()`
- Отправляет правильный заголовок `Content-type: text/html`
- **Дополнительно**: обрабатывает POST запросы и выводит данные в консоль
